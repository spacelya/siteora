# First demo and first Fiverr gig

## Beauty salon demo

Atelier Nour is already included as a working first concept: responsive layout, sample MAD service menu, and a booking enquiry preview that sends nothing. It is a fictional business, not client work.

Before using it as your principal sample:
1. Review the demo on your phone; check the menu, date field, and booking preview.
2. Decide whether to add French and Arabic. Translate and review each language properly; Arabic requires an RTL layout review. The current site is English only.
3. If adding photos, use your own or commercially licensed images and keep licence records. Never invent salon staff or customer testimonials.
4. Keep the booking preview labelled as a demo. For a real client, agree an existing booking provider or enquiry method, costs, privacy needs, and confirmation process before adding it.
5. Capture original desktop and phone screenshots for your Fiverr portfolio. Label them “self-initiated fictional salon concept”. Do not include contact details, external URLs, payment details, or a link funnel in the Fiverr images.

## First Fiverr listing (draft plan, not published)

Suggested title: “I will create a responsive AI assisted website for your small business”.

Positioning: New independent seller offering focused static websites with AI assistance, personal customization, and manual review. Do not claim expert programming experience, client counts, guaranteed revenue, or rankings.

Start with a narrow one-page package. Specify sections, supplied content, included revisions, delivery time, source files, and hosting assistance. Price only after timing a complete practice project and accounting for Fiverr fees. Add larger packages only when you can reliably deliver them.

Collect: business description, target audience, logo and licensed photos, page content, reference styles, required action, and existing hosting details. Do not ask clients to send account passwords in messages. Use appropriate delegated access when needed.

Suggested description opening:
“I create clear, responsive static websites for small businesses using an AI-assisted workflow. Each project is customized around your content and goals, then reviewed before delivery. My portfolio currently shows self-initiated concepts, not past client projects. Please message me on Fiverr so we can agree the scope before you order.”

Keep Fiverr buyer communication, orders, delivery, and payment on Fiverr. Use Fiverr's own portfolio and approved attachments to show work. Do not send buyers to the agency site's email form or include contact details in Gig images. Review current rules when creating the listing:
- https://help.fiverr.com/hc/en-us/articles/37554769759633-Stay-protected-Fiverr-s-off-platform-policy
- https://help.fiverr.com/hc/en-us/articles/34551010553489-Account-restrictions

## Keep costs at zero initially

Use the free pages.dev address and the existing GitHub account. No custom domain, paid builder, paid booking app, advertising spend, database, or ongoing service subscription is required for these files. Reassess only when a specific paying project needs more.
